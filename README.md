One image that sums up Tuesday 17 November 2026: strikes on bridges in Kyiv and Crimea,
Iran's drones at a US radar facility in Bahrain, the 49th ASEAN summit closing in Manila,
a market sell-off led by AI stocks, a military plane crash in Russia, and the call for
more aid into Gaza. The date is printed large in the masthead and repeated in the footer.
The six panels are color-coded so the day reads at a glance.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` uses only the Python standard library: it copies the committed `entry.png`
into `/output/entry.png`. The image itself was drawn with `draw.py` (Pillow is a
build-time tool only, never imported by the entry) and reviewed before submission.
